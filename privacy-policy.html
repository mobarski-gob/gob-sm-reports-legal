Privacy Policy – GOB SM Reports

Last updated: 26 October 2026

1. Who we are

GOB SM Reports is an internal tool operated by Go On Board (goonboard.com), a board game publisher. Contact: m.obarski@goonboard.com.

2. What the application does

The application connects to the company's own YouTube channel through the YouTube Analytics API and the YouTube Data API, using read-only permissions (youtube.readonly and yt-analytics.readonly). It reads channel and video statistics (e.g. views, watch time, subscribers gained and lost, traffic sources, audience countries and aggregated age/gender shares) and public metadata of the channel's videos. It does not post, edit or delete anything on the channel.

3. Data we handle

Only aggregated analytics of the company's own channel and the OAuth refresh token needed to read them. We do not collect personal data of viewers, subscribers or other third parties; the application does not have access to it.

4. How the data is used and stored

The statistics are written to the company's internal Google Sheets reports and are used only for internal reporting and marketing analysis. The OAuth token is stored as an encrypted secret in the company's private code repository. Data is not sold, shared with third parties or used for advertising.

5. Google API Services User Data Policy

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and revoking access

Statistics are kept in the company's reports for as long as they are useful for reporting. Access can be revoked at any time at myaccount.google.com/permissions or by contacting us; after revocation the application can no longer read the channel's data.

7. Changes

We may update this policy; the date above shows the latest version.
